# smartdevelopers.dev

The public site for the smartdevelopers.dev domain: a landing page and the
published policies the app stores require a reachable URL for.

- `index.html` — landing page
- `dawami/privacy/index.html` — privacy policy for the Dawami attendance app,
  Arabic and English, linked from Google Play and App Store Connect

No application code lives here. Edit the policy in this repository, not in the
app repository, so that the published page and the submitted URL never drift
apart.
